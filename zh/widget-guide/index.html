怎么把倒数日放到 iPhone 主屏幕和锁定屏幕

把倒计时放在主屏幕上，每次解锁手机都能看到还有几天。大约一分钟就能设置好。下面的步骤使用 Simple Count，它免费，所有小组件都免费。

添加到主屏幕

  1. 先添加一个倒计时。在 App Store 下载 Simple Count，轻点 +，输入名称和日期，选择表情或颜色。也可以对 Siri 说“在 Simple Count 中添加倒计时”，再说出是什么事、哪一天。
  2. 在主屏幕空白处按住，轻点左上角的“编辑”，然后轻点“添加小组件”。iOS 17 上轻点左上角的“+”。
  3. 搜索“Simple Count”并轻点它。
  4. 滑动选择尺寸（小、中、大），然后轻点“添加小组件”，拖到想放的位置后轻点“完成”。
  5. 按住小组件，然后轻点“编辑小组件”。保持“下一个事件”即可始终显示最近的倒计时，或轻点“事件”选择一个。

添加到锁定屏幕

  1. 用面容 ID 解锁后，按住锁定屏幕。
  2. 轻点“自定”（如有提示，选择“锁定屏幕”）。
  3. 轻点时间下方的方框。
  4. 找到 Simple Count，轻点一个小组件来添加。
  5. 轻点小组件选择倒计时，然后轻点“完成”。

在灵动岛上看实时倒计时

编辑倒计时时，打开“显示倒计时”并设置时间。在开始前的最后六小时，Simple Count 会在锁定屏幕和灵动岛上显示实时活动，精确到秒，自动开始；可以在设置中关闭。

小组件没出现？

  • 小组件列表里找不到 Simple Count？先打开一次 App，再试一次。
  • 小组件还显示旧的倒计时？按住它，轻点“编辑小组件”，重新选择倒计时。如果还是没有刷新，重启 iPhone 即可。
  • 还是不行？在 Simple Count 中打开“设置”→“如何添加小组件”，会用动画一步一步演示。
